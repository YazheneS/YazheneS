## Featured Projects

### [Pocket CFO](https://github.com/YazheneS/pocketCFO) — AI-Powered Financial Management Platform
> An integrated monorepo for small-business finance with conversational AI, voice input, and a full REST API

- **Chainlit chat UI** — log transactions in plain English ("Spent Rs.500 on rent")
- **Voice module** — Groq Llama-powered natural language parsing and AI categorisation
- **FastAPI backend** — CRUD, advanced filtering, CSV/PDF export, Supabase PostgreSQL
- **Docker Compose** — 4-service orchestration (API, Chainlit, Voice, Ollama LLM)

`Python` `FastAPI` `Chainlit` `Ollama` `Groq` `Supabase` `Docker`

---

### [Doctor Prescription System](https://github.com/YazheneS/doctorPrescription) — Automated Prescription Management
> MERN fullstack app that digitises handwritten prescriptions with OCR + LLM — 85%+ accuracy, sub-100 ms API

- **Azure Document Intelligence** OCR extracts text from images/PDFs
- **Groq LLM** normalises medicine names, dosages, and frequencies
- Doctor panel: create, upload, export prescriptions as PDF
- JWT auth, bcrypt passwords, role-based access (Doctor / Patient)
- 9/9 functional tests passing | O(log n) DB queries | 15 API endpoints

`React` `Node.js` `Express` `MongoDB` `Azure AI` `Groq` `JWT` `PM2` `Nginx`

### [Traffic Police Management System](https://github.com/YazheneS/Traffic-police-management-system) — Full-Stack Team Project
> A multi-module management system built by a 5-person team for drivers, vehicles, violations, challans & payments

- Modules: Driver, Vehicle, Violation, Challan, Payment + Dashboard
- Analytics dashboard with live summary from MySQL
- Login system with role-based access
- Feature-branch workflow with PRs per module

`React` `Vite` `Node.js` `Express` `MySQL`

### [Student Result Report Generator](https://github.com/YazheneS/Student-result-report-generator) — Java Desktop App
